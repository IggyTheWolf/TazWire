# TazWire

> [!WARNING]
> Untested Alpha version! Use at your own risk!

Lulzbot Taz6 to core XZ via Voron Switchwire

## Controller boards

The TazWire conversion can be used with different controller boards:

| Board | Status | Files |
|---|---|---|
| RAMBo (stock TAZ 6) | **Untested draft** Klipper config | [klipper/tazwire-rambo-printer.cfg](klipper/tazwire-rambo-printer.cfg) |
| Archim2 | Klipper configs | [klipper](klipper) |
| BIGTREETECH Manta E3EZ | **Untested draft, not yet powered on** | [Manta Board](Manta%20Board/README.md) |
